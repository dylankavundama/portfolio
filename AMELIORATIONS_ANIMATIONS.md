## 🎯 Types d'Animations Implémentées

### Animations d'Entrée
1. **fadeInLeft** - Entrée depuis la gauche
2. **fadeInRight** - Entrée depuis la droite
3. **fadeInUp** - Entrée depuis le bas
4. **scaleIn** - Agrandissement progressif
5. **letterFadeIn** - Animation lettre par lettre avec rotation 3D

### Animations au Hover
1. **Élévation** - translateY avec ombre
2. **Scale** - Agrandissement au survol
3. **Rotation** - Rotation légère pour les technologies
4. **Ripple** - Effet de vague au clic

### Animations Continues
1. **Pulse** - Pulsation pour l'image hero
2. **Float** - Mouvement flottant pour les particules

### Animations au Scroll
1. **Intersection Observer** - Détection de visibilité
2. **Stagger** - Délais séquentiels pour les éléments multiples
3. **Parallax** - Effet de profondeur

## 🎨 Palette d'Animations

### Vitesses
- **Rapide** : 0.2s - 0.3s (hover, clics)
- **Moyenne** : 0.5s - 0.6s (entrées d'éléments)
- **Lente** : 0.8s - 1s (sections complètes)

### Easing
- **cubic-bezier(0.4, 0, 0.2, 1)** - Standard Material Design
- **ease-out** - Pour les entrées
- **ease-in-out** - Pour les animations continues
