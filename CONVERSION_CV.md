# 📄 Conversion du CV HTML en PDF

## ✅ CV HTML créé

Un CV HTML moderne et professionnel a été créé: `dylan_cv.html`

## 🔄 Méthodes de conversion en PDF

### Méthode 1: Via le navigateur (Recommandé - Simple)

1. Ouvrez `dylan_cv.html` dans votre navigateur (Chrome, Edge, Firefox)
2. Appuyez sur `Ctrl + P` (ou `Cmd + P` sur Mac)
3. Sélectionnez "Enregistrer en PDF" comme destination
4. Cliquez sur "Enregistrer"
5. Le fichier `dylan_cv.pdf` sera créé

### Méthode 2: Via Puppeteer (Node.js)

Si vous avez Node.js installé:

```bash
npm install puppeteer
node convert_cv_to_pdf.js
```

### Méthode 3: Via un service en ligne

- [HTML to PDF](https://www.html2pdf.com/)
- [PDF24](https://tools.pdf24.org/fr/html-vers-pdf)
- [ILovePDF](https://www.ilovepdf.com/fr/html-en-pdf)
